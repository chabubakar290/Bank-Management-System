# Bank Management System (Node.js CLI)

## Overview

This is a Command Line Interface (CLI) Bank Management System built with Node.js and the `readline` module. The project simulates the basic operations of a banking system by allowing users to create accounts, manage balances, and track transactions through an interactive menu.

The project was developed to practice JavaScript fundamentals, including arrays, objects, loops, functions, conditionals, user input handling, and object manipulation.

---

## Features

- Create a new bank account
- View account details
- Deposit money into an account
- Withdraw money with insufficient balance validation
- Check current account balance
- View transaction history
- Input validation for account numbers and monetary values
- Menu-driven interactive CLI

## How to Run

1. Install Node.js.
2. Clone this repository.
3. Open the project folder in your terminal.
4. Run the following command:

```bash
node BankManagementSystem.js
```
